# Rock Paper Scissors

A Rock Paper Scissors game with a simple browser UI, built while learning JavaScript through The Odin Project.

## Features

- Click Rock, Paper, or Scissor buttons to play against the computer
- Game runs for 5 rounds
- Live score display for human and computer
- Round counter (`Round: X of 5`)
- Shows both choices after every round
- Displays the final result (Human Wins / Computer Wins / It's a Tie)
- Retry button to reset the game and play again
- Choice buttons are disabled once the game is over

## What I Practiced

- JavaScript functions and variables
- `if / else if` and loops
- `Math.random()` for the computer's choice
- DOM selection with `querySelector` / `querySelectorAll`
- Event listeners for button clicks
- Updating the page with `textContent`
- Creating and removing elements (`createElement`, `remove()`)
- Disabling buttons with the `disabled` property
- CSS layout with Flexbox
- Git & GitHub

## How to Run

Open `index.html` in a browser and click the buttons to play.

The game is fully playable from the page — the browser console just shows extra logs for each round and the final result.
