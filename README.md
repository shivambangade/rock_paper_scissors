# Rock Paper Scissors

A simple Rock Paper Scissors game made while learning JavaScript through The Odin Project.

## What I Practiced

- JavaScript functions
- Variables
- `if / else if`
- Loops
- `Math.random()`
- User input with `prompt()`
- Basic score tracking
- Git & GitHub

## How to Run

Open `index.html` in a browser and open the browser console.

The game runs for 5 rounds.
